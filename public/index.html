03 / YOUR BROWSER, YOUR CALL

Control stays
with the user.

A browser extension can expose a narrow, user-approved capability to DARLE. The extension—not the website—executes locally. You can see its status, restrict which sites it can access, and revoke access independently.

Browser control is a proposed connector direction, not a currently available feature. Browser APIs and extension-store policies differ by platform.

04 / SECURITY MODEL

Power with
clear boundaries.

Local execution is not automatically safe. DARLE is being designed around least privilege, explicit grants, bounded inputs, visible activity and honest failure states.

01Specific permissions

Grant access per workflow, connector, action and capability.

02Local execution boundary

Keep the control plane separate from the component that performs device actions.

03Visible and revocable

Show what is connected, what ran and how to stop or revoke it.
