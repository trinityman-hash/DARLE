03 / UNDER THE SURFACE

One answer.
Several gates.

Each layer has a bounded responsibility. The verifier does not pretend to know what it cannot establish.

01

ROUTE

Arithmetic and supported memory questions bypass generation. The system uses a dedicated calculator or retrieves a stored proof.

↗
02

RECALL

Relevant known facts are retrieved and supplied as context. User-stated facts remain distinct from model-generated statements.

↗
03

GENERATE

The language layer returns a strict structured response. Runtime validation rejects malformed output before it can be used.

↗
04

VERIFY

Supported claims are checked against the system's knowledge. Contradictions trigger a correction attempt; unresolved answers can be declined.

↗

04 / ENGINEERING HONESTY

Evidence has
an edge.

DARLE can check structure, arithmetic, and consistency with facts it holds. It cannot guarantee that all model statements are true, that its memory is complete, or that a deployment is immune to attack. Treat unverified claims as unverified.
